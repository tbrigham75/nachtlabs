# ADR 0003: immutable governance and protected definitions

Use document heads, immutable versions and separate immutable human approval. New drafts do not replace approved versions. Mission approval requires approved baseline Journeys. Runtime roles cannot modify audit/version/approval history.

Holdout bodies occupy a separate encrypted table and human-restricted endpoints. Generic views/audit omit them. This protects definitions; execution isolation and independent verification are later gated work. One organization is enforced while retaining project/organization relationships for later expansion.
